# Contributing

This repository currently accepts architecture and runbook work only. Installer implementation begins in a later phase. Retain the original MIT license and document the origin/license of any future reused code.

Use [shared contribution guidance](https://github.com/IbisPanel/docs/blob/main/CONTRIBUTING.md). Future executable changes require isolated platform tests, repeat-run and interruption recovery checks, secret redaction, manual parity and an explicit supported OS/component matrix. No deployment, push or live repair was authorized in Phase 0.
