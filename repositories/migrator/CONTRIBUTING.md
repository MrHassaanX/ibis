# Contributing

Phase 0 is design only. Do not add executable adapters, migration scripts or copied panel implementations here. Use [shared contribution guidance](https://github.com/IbisPanel/docs/blob/main/CONTRIBUTING.md) and preserve the initial MIT license.

Future adapters require exact supported source versions, primary-source mapping research, synthetic/anonymized fixtures, read-only dry-run tests, unsupported-data reporting, secret redaction, backup restore evidence and interrupted-run recovery checks. Never use a real customer's export as a public fixture.
